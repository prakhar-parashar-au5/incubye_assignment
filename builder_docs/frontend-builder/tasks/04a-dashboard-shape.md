**Status:** READY

## Goal

Create the UX and interface plan for the compensation dashboard before backend analytics endpoints exist.

Do not write production UI code in this task.

## Use Impeccable

Use the existing product and design context. Run context once for this session. Use shape guidance for an Operate surface.

Do not create a new visual world. Do not enable hooks or live mode.

## Produce

- Dashboard route and navigation change.
- First-viewport information hierarchy.
- Top-figure layout.
- Native currency separation.
- USD-comparison disclosure.
- Global filters and URL state.
- Department, country, currency, level, and status breakdown interaction.
- Recent recorded salary changes.
- Pending and stale request area.
- Upcoming compensation changes.
- Employees without a recorded adjustment.
- Links into employee directory, employee detail, and approval queue.
- Desktop and mobile layout.
- Keyboard and focus behavior.
- Loading, empty, missing-rate, invalid-filter, expired-session, and backend-unavailable states.
- Proposed chart types with a reason for each.
- Browser test journeys.
- Exact backend API questions required before implementation.

Keep the dashboard useful within ten seconds. Avoid a wall of cards or charts.

Do not modify frontend or backend production code. Do not invent API response types. Do not run Git commands.
