# AI observability persistence foundation

This change adds the seven-table MySQL storage model, repository boundary, recursive JSON redaction and size checks, and a guarded retention command without wiring live assistant, MCP, HTTP, or frontend paths. The schema and transaction strategy cover ownership, ordering, cascade, terminal-transition, review-CAS, and retention requirements. Four contract gaps remain in repository output, rejected-call state, idempotency handling, and migration verification.

**Watch for:** **confirmed** incomplete Admin trace-list records; **confirmed** rejected tool and MCP calls can retain results; **confirmed** idempotency keys can be accepted without a usable command hash; **confirmed** the migration test does not verify every required foreign key, delete rule, constraint, and index.

**Verdict**: NEEDS_CHANGES

## High-level view

The migration defines the intended aggregate boundaries. Sequence allocation serializes on the conversation row, terminal trace totals come from child rows, review replacement locks the trace, and retention deletes bounded batches.

**Confirmed:** `listTraces` selects token and failure fields but discards them, and it never returns the tool names required by the Admin list (`repository.ts:239-255`).

**Confirmed:** a `REJECTED` tool or MCP finalization can include and persist `result`, creating a record that says execution was rejected while retaining an execution result (`repository.ts:192-202`, `224-235`).

**Confirmed:** providing `idempotencyKey` without `commandHash` stores SQL `NULL`; replay compares that value with JavaScript `undefined` and raises a conflict instead of returning the existing trace (`repository.ts:126-153`).

**Confirmed:** the schema test samples only two foreign keys and selected indexes, despite the task requiring verification of every foreign key, unique constraint, required index, and delete behavior (`observability-storage.test.ts:30-45`).

## Admin trace summaries omit required observability fields

**Confirmed:** `listTraces` queries `failure_stage`, `input_tokens`, `output_tokens`, and `reasoning_tokens`, then drops all four while mapping rows. It filters by tool name through `EXISTS` but does not return tool names. The later Admin route cannot satisfy the specified list contract from this operation without another query or repository change.

Return a defined trace-summary type with the required fields and an aggregated, bounded tool-name list. Add an integration assertion over the complete returned shape.

## Rejected calls can carry execution results

**Confirmed:** `finishToolCall` and `finishMcpCall` serialize and write `input.result` for every terminal status. The integration test reinforces the invalid combination by finalizing a rejected assistant tool call with salary result data. Because rejection means validation prevented execution, this can hide accidental execution behind `REJECTED`.

Reject `result` for `REJECTED` and use discriminated terminal input types. Move the salary-preservation assertion to a `SUCCEEDED` tool call.

## Optional idempotency fields break replay

**Confirmed:** `createTrace` allows `idempotencyKey` and `commandHash` independently. A key without a hash stores `NULL`; replay evaluates `null !== undefined` and conflicts even when the command is unchanged. A hash without a key is also accepted but has no effect.

Require both fields or neither, validate before the transaction, and test same-key/same-hash reuse and same-key/different-hash conflict.

## Schema assertions cover only sampled integrity rules

**Confirmed:** the migration test checks table names, two foreign-key/delete-rule combinations, selected index names, and unique-index names. It omits the remaining foreign keys, most cascade/restrict rules, index column order, and non-negative/status-time checks. Regressions in those definitions would leave the test green.

Compare complete information-schema results for foreign keys and delete rules, ordered unique/index columns, and required check constraints.

The builder-reported database result was not independently reproduced.
